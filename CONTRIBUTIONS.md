# Contributing to Weather + Outfit Suggester

We welcome contributions! Please follow these steps to contribute:
1. Pick an issue from the GitHub Project board and move it to **In Progress**.
2. Create a feature branch from `main` (`git checkout -b feature/your-feature-name`).
3. Commit your changes and ensure all tests pass (`flutter test` / `npm test`).
4. Open a Pull Request referencing the issue. Ensure CI checks pass and request a review.
